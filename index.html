Admin tools & operational notes

Security

Admin authorization checks the users/{uid} profile role. Set role=admin in Firestore for authorized admin accounts. Restrict Firestore rules so only authorized admins can access admin collections and customer records.

Data collections used

users, businesses, invites, supportTickets, paymentRecords, adminLogs. Existing customer and subscription data continues to use your users and businesses structure.

Important limitations

This page is a client-side admin interface. Access control must be enforced in Firestore security rules and preferably server-side functions. Admin UI visibility is not a security boundary. Subscription suspension behavior in the customer app must also enforce the businesses.active / users.active status.

Support and payments

Ticket notes and manually recorded payments are written to Firestore. You need to configure Firestore rules for these collections before use.
